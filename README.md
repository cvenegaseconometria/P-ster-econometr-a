# Proyecto de Econometría II

## Descripción
Proyecto académico de Econometría II de la Universidad Nacional de Colombia, sede Bogotá, orientado al análisis de series de tiempo y la elaboración de pronósticos mediante la metodología Box-Jenkins.

## Archivos
- `Econometría - Póster.py`: código fuente del análisis econométrico.
- `anex-IPC-sep2026.xlsx`: base de datos utilizada para el análisis del IPC.

## Herramientas
- Python
- Pandas
- NumPy
- Matplotlib
- Statsmodels

## Ejecución
Para ejecutar el código, se requiere Python y las bibliotecas utilizadas en el análisis. La base de datos debe estar disponible en la ruta que espera el código.
